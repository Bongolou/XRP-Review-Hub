## How to read this list

- **Active XRPL user?** Start with Xaman. It's free and unmatched on
  DEX, AMM, NFT, and xApp coverage.
- **Holding more than you can afford to lose?** Add a hardware wallet
  for cold storage. Ledger or Trezor for the classic USB experience,
  Tangem for the smallest form factor, ELLIPAL if you want zero
  connectivity at all.
- **Power users do both:** software wallet for activity, hardware
  wallet for the bulk of the bag.

---

## Two-minute decision rules

1. If you only own a small starter position, a software wallet is
   fine — Xaman is our pick.
2. The moment your XRP is worth more than your phone, get a hardware
   wallet. Don't wait.
3. Buy hardware only from the manufacturer's official store. Never
   from Amazon or a marketplace reseller.
4. Write the seed phrase on paper. Store it offline. Never type it
   into any computer or take a photo of it.
5. Send a small test transaction (1 XRP) before moving any larger
   amount.
