## 2. トラストライン + AMM の安全チェックリスト

XRPL DeFi で失われたお金のほとんどは「ハッキング」によるものでは
ありません。詐欺トークンに対してトラストラインを開いたり、プールの
両側を確認せずに AMM に参加したりしたことが原因です。署名する前に
毎回このリストを確認してください。

### トラストラインを設定する前に

- [ ] 発行者アドレスがプロジェクト公式サイトのものと一致している
      （手で打たず、コピー＆ペースト）。
- [ ] そのトークンが Bithomp または XRPSCAN に検証済みのエントリ
      を持っている — ロゴと Telegram リンクだけでない。
- [ ] トラストラインに **適切な上限**（例: 10,000）を設定している。
      既定の「無制限」のままにしない。無制限のトラストラインは、
      悪意ある発行者にあなたのウォレットへ無制限に発行する権限を
      与えてしまいます。
- [ ] 発行者が設定している **転送手数料** を理解している。1% を
      超えるものは本物のプロジェクトではまず見られません。
- [ ] トラストライン 1 本につき 2 XRP の予約（ロックされるだけで
      消費はされません。トラストラインを削除すれば戻ります）に
      納得している。

### AMM に入金する前に

- [ ] プールの両側に **実際に取引されている流動性** がある。単一の
      LP が 99% を保有しているだけではない。
- [ ] 現在のスプレッドと 24 時間出来高を確認した。出来高 0 ドルの
      プールは、APR ウィジェットがどう表示しても手数料を生みません。
- [ ] **無常損失（インパーマネントロス）** を理解している。価格比
      が変わると、負けた資産が増え、勝った資産が減ります。価格が
      両方とも元に戻らない限り損益分岐に到達しません。
- [ ] **少なくとも 30 日**は置いておける金額を入れている。XRPL の
      AMM LP ポジションには小さな解除コストがあります。
- [ ] 「自動複利」「APR ブースト」のコントラクトを **一度も** クリ
      ックしていない。XRPL ネイティブ AMM にそんな機能はありませ
      ん — そうしたリンクは詐欺です。

### 署名した後

- [ ] Bithomp を開いて自分のアドレスを貼り付け、トラストラインや
      AMM 預入が想定どおりに表示されているか確認する。
- [ ] 何かおかしい場合 — 発行者が違う、金額が違う、見覚えのない
      トークン — ただちにトラストラインを削除する。あとからいつでも
      再追加できます。

## 3. Xaman のセットアップ（モバイル、無料、日常用）

Xaman は XRPL Labs（XRPL バリデータも運営している同じチーム）が
開発しています。多くの XRPL dApp が標準で接続するウォレットです。

1. App Store または Google Play から **Xaman** をインストール。
   インストール前に開発者が **XRPL Labs B.V.** であることを確認。
2. アプリを開き **Create a new account** を選択。
3. **Full access**（あなたが秘密を管理）を選ぶ。"Read only" は
   選ばない。
4. 24 単語ニーモニックではなく **Secret Numbers** を選ぶ。Secret
   Numbers は XRPL ネイティブで、紙のバックアップが容易です。
5. 8 行の Secret Numbers を順番どおりに紙に書き写す。耐火性のある
   場所に保管する。**写真を撮らない。Xaman 以外のどこにも入力しない。**
6. 取引所から最初の 10 XRP を送って口座を有効化する。XRPL は
   1 XRP のベース予約が必要なので、少なくとも 2 XRP 送らないと
   トランザクションが失敗します。
7. **Settings → Security** で Face ID / 指紋を有効化し、6 桁 PIN
   を設定する。
8. dApp を使うとき: スマホのブラウザで dApp を開き、"Connect
   Xaman" をタップ、Xaman アプリ内で署名リクエストを承認する。
   秘密鍵を dApp に貼り付けることはありません。

任意ですが推奨: Xaman を Tangem カードや Ledger とペアリングする
と、秘密鍵がスマホに残らなくなります。Settings → Accounts → Add
account → Import from hardware。

## 4. Crossmark のセットアップ（デスクトップ、無料、ブラウザ dApp 用）

Crossmark は「XRPL 版 MetaMask」と呼ばれる存在です。ブラウザ拡張
として動くため、ノート PC から XRPL dApp を使う最も簡単な方法です。

1. **https://crossmark.io** に直接アクセス（検索しないこと —
   偽の拡張機能が存在します）。**Install for Chrome / Brave / Edge**
   をクリック。
2. 追加する前に、拡張機能の発行元が **Crossmark** であることを確認。
3. 拡張を開き、**Create new wallet** を選ぶ。
4. 24 単語のシードフレーズを紙に書き留める。物理的に保管し、パス
   ワードマネージャーやクラウドには絶対に入れない。
5. 強力な拡張パスワードを設定する。これはあなたの端末上で拡張を
   解除するだけで、シードが漏れた場合の保護にはなりません。
6. ベース予約を満たすため、取引所から 2 XRP 以上を送って口座を
   有効化する。
7. dApp を使うとき: dApp サイトを開き "Connect Crossmark" を
   クリック、拡張ポップアップで承認する。署名前に必ず取引内容
   （トークン、金額、宛先）を読むこと。
8. **拡張機能をツールバーに固定** し、偽ポップアップを見分けられる
   ようにする。本物の Crossmark のプロンプトは常に固定されたアイ
   コンから来ます。

ヒント: 小額の "DeFi 実験用" Crossmark プロファイルを別に用意し、
長期保有用には Xaman + ハードウェアウォレットを使う。新しい dApp
に main ウォレットを接続しないこと。
