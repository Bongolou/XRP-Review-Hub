# All Things XRPL — XRPL DeFi 스타터 키트

XRP Ledger의 DeFi에 오신 것을 환영합니다. 이 키트는 가장 먼저 시도해
볼 만한 dApp, AMM이나 트러스트라인에 손대기 전에 자금을 지키는 안전
점검, 그리고 일상에서 실제로 쓰게 될 두 지갑(Xaman과 Crossmark)을
정확히 어떻게 설정해야 하는지 안내합니다.

인쇄해도 좋고, 캡처해 두어도 좋고, 탭에 열어둬도 좋습니다 — 모든
링크는 모바일과 데스크톱에서 모두 동작합니다.

## 1. 어떤 XRPL dApp을 먼저 써볼까

XRPL의 DeFi 생태계는 작고 집중되어 있습니다. 스무 개의 프로토콜을
배울 필요가 없습니다. 다음 다섯 개를 — 이 순서대로 — 시작하세요.
한나절도 안 되어 AMM, DEX, NFT 마켓, 온체인 대출까지 모두 사용해본
셈이 됩니다.

| #  | dApp              | 설명                                           | 먼저 해볼 것                                                 |
|----|-------------------|------------------------------------------------|--------------------------------------------------------------|
| 1  | XPMarket          | 토큰 런치패드 + AMM 대시보드                   | 1 XRP를 상장 토큰으로 스왑하고 AMM 체결을 관찰              |
| 2  | Sologenic DEX     | XRPL 네이티브 오더북 DEX (AMM 없음)            | USD IOU에 대해 소액 지정가 주문 넣어보기                    |

## 2. 트러스트라인 + AMM 안전 체크리스트

XRPL DeFi에서 잃는 돈은 대부분 "해킹"으로 사라지는 것이 아닙니다.
사기 토큰에 트러스트라인을 열거나, 풀의 양쪽을 확인하지 않고 AMM에
들어가면서 잃습니다. 서명할 때마다 매번 이 목록을 점검하세요.

### 트러스트라인을 설정하기 전에

- [ ] 발행자 주소가 프로젝트 공식 사이트의 주소와 일치하는지 (직접
      입력 말고 복사·붙여넣기로) 확인.
- [ ] 해당 토큰이 Bithomp나 XRPSCAN에 검증된 항목으로 등재되어
      있는지 — 단지 로고와 텔레그램 링크뿐이면 곤란합니다.
- [ ] 트러스트라인에 **합리적인 한도**(예: 10,000)를 설정했는지.
      기본값인 "한도 없음"을 그대로 두지 마세요. 한도가 없으면
      악의적 발행자가 당신 지갑에 무제한으로 토큰을 발행할 수 있
      습니다.
- [ ] 발행자가 설정한 **전송 수수료**를 이해하고 있는지. 1%가
      넘으면 진짜 프로젝트에서는 보기 드뭅니다.
- [ ] 트러스트라인당 2 XRP 예약이 잠긴다는 점을 받아들이는지
      (사용되는 게 아니라 잠기는 것이며, 트러스트라인을 제거하면
      돌려받습니다).

### AMM에 예치하기 전에

- [ ] 풀의 양쪽에 **실제로 거래되는 유동성**이 있는지 — 단일 LP가
      99%를 보유한 것은 아닌지.
- [ ] 현재 스프레드와 24h 거래량을 확인했는지. 일일 거래량이 0
      달러인 풀은 APR 위젯이 무엇을 보여주든 수수료를 벌지 못합
      니다.
- [ ] **임퍼머넌트 로스**를 이해했는지: 가격 비율이 바뀌면 손실 자
      산은 늘고 이익 자산은 줄어듭니다. 양쪽 가격이 모두 회복돼야
      만 손익분기에 도달합니다.
- [ ] **최소 30일**은 두고 갈 수 있는 금액을 예치하는지. XRPL
      AMM LP 포지션은 약간의 해지 비용이 있습니다.
- [ ] "자동 복리"나 "APR 부스트" 같은 컨트랙트를 **한 번도** 누른
      적이 없는지. 네이티브 XRPL AMM에는 그런 기능이 없습니다 —
      그런 링크는 사기입니다.

### 서명 후

- [ ] Bithomp를 열고 주소를 붙여넣어 트러스트라인 / AMM 예치가
      예상한 그대로 보이는지 확인.
- [ ] 무언가 이상하다면 — 발행자가 다르거나, 금액이 다르거나,
      낯선 토큰이 보이면 — 즉시 트러스트라인을 제거하세요. 언제든
      다시 추가할 수 있습니다.

## 3. Xaman 설정 (모바일, 무료, 일상용 메인)

Xaman은 XRPL Labs(XRPL 검증인을 운영하는 같은 팀)에서 만듭니다.
대부분의 XRPL dApp이 기본으로 연결하는 지갑입니다.

1. App Store 또는 Google Play에서 **Xaman**을 설치하세요. 설치
   전에 개발자가 **XRPL Labs B.V.**인지 확인하세요.
2. 앱을 열고 **Create a new account**를 선택.
3. **Full access**(당신이 비밀을 통제)를 선택 — "Read only"는
   선택하지 마세요.
4. 24단어 니모닉이 아닌 **Secret Numbers** 옵션을 선택하세요.
   Secret Numbers는 XRPL 네이티브이며 종이에 백업하기가 더 쉽
   습니다.
5. 8줄의 Secret Numbers를 순서대로 종이에 적으세요. 화재 안전한
   곳에 보관하세요. **사진 찍지 마세요. Xaman 이외의 그 어디에도
   입력하지 마세요.**
6. 계정을 활성화하기 위해 거래소에서 첫 10 XRP를 송금하세요. XRPL
   은 1 XRP의 기본 예약이 필요하므로 최소 2 XRP를 보내야 트랜잭
   션이 실패하지 않습니다.
7. **Settings → Security**에서 Face ID / 지문을 켜고 6자리 PIN을
   설정하세요.
8. dApp 사용 방법: 모바일 브라우저에서 dApp을 열고 "Connect
   Xaman"을 누른 뒤 Xaman 앱 안에서 서명 요청을 승인합니다. dApp
   에 비밀을 붙여넣을 일은 절대 없습니다.

선택이지만 권장: Xaman을 Tangem 카드나 Ledger와 페어링하면 비밀
이 폰에 전혀 저장되지 않습니다. Settings → Accounts → Add account
→ Import from hardware.

## 4. Crossmark 설정 (데스크톱, 무료, 브라우저 dApp용)

Crossmark는 "XRPL의 MetaMask"입니다. 브라우저 확장으로 동작하므로
노트북에서 XRPL dApp을 가장 쉽게 쓸 수 있는 방법입니다.

1. **https://crossmark.io**로 직접 들어가세요(검색하지 마세요 —
   가짜 확장이 존재합니다). **Install for Chrome / Brave / Edge**
   를 클릭합니다.
2. 추가하기 전에 확장의 게시자가 **Crossmark**인지 확인하세요.
3. 확장을 열고 **Create new wallet**을 선택.
4. 24단어 시드 문구를 종이에 적으세요. 비밀번호 관리자나 클라우드
   가 아니라 물리적으로 보관하세요.
5. 강력한 확장 비밀번호를 설정하세요 — 이는 당신의 기기에서 확장
   을 잠금 해제할 뿐, 시드가 유출됐을 때 보호해주지는 않습니다.
6. 기본 예약을 충족하도록 거래소에서 2 XRP 이상을 송금해 계정을
   활성화하세요.
7. dApp 사용 방법: dApp 사이트를 열고 "Connect Crossmark"를 클릭
   한 뒤 확장 팝업에서 승인합니다. 서명 전에 트랜잭션 페이로드
   (토큰, 금액, 수신지)를 항상 읽으세요.
8. 가짜 팝업을 알아챌 수 있도록 **확장을 도구모음에 고정**하세요.
   진짜 Crossmark 프롬프트는 항상 고정된 아이콘에서 나옵니다.

팁: 소액의 "DeFi 실험용" Crossmark 프로필을 따로 두고, 장기 보유는
Xaman + 하드웨어 지갑 조합으로 가져가세요. 메인 지갑을 새로 나온
dApp에 절대 연결하지 마세요.
